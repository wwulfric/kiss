kiss
安装指南 GitHub

coding agent 的 skill 仓库

装进 kiss 的 skill 平时不进上下文。你输入 /kiss <name>， 它才把那一个 SKILL.md 交给 agent。kiss 不执行脚本，也不调用模型。

curl -fsSL https://raw.githubusercontent.com/wwulfric/kiss/master/scripts/install.sh | bash irm https://raw.githubusercontent.com/wwulfric/kiss/master/scripts/install.ps1 | iex

装好后运行 kiss setup，agent 里就有 /kiss 了。

用过 npx skills？把前缀换掉就行：

- npx skills add owner/repo@tdd+ kiss add owner/repo@tdd

source 写法和 --skill、--all、--list 都一样。 已经用 npx skills 装过的，运行 kiss import --all 导入。 

$ kiss add owner/repo --skill browser-test
Installed browser-test

> /kiss browser-test url=https://example.com

# KISS loaded skill: browser-test

## User invocation
- Skill: browser-test
- Args: url=https://example.com

## Skill instructions
（browser-test/SKILL.md 的内容）

## KISS runtime notes
- Only this skill was loaded.
